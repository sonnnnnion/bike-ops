Videos

How-to library. In Bike Manager mode you can add or remove videos at any time.

Paste the Share link — it gets converted automatically. Google Drive, Google Slides and YouTube share links don't embed as-pasted; the site rewrites them for you. But the file itself must be shared “Anyone with the link → Viewer”, or it shows a sign-in wall instead of playing. Training videos and decks aren't sensitive, so link-sharing those is fine — it's the check Sheets that must stay Restricted.

Lectures

The bike lecture, split into modules. The deck lives in Google Slides — editing happens there, so the file stays the single source of truth.

One deck, six modules. Link the deck once below and each module opens it at its own slide. Paste the normal Slides share link — it's converted to an embed automatically — but set the deck to “Anyone with the link → Viewer” first, or every module shows a sign-in wall. If a module lands on the wrong slide, open that slide in Slides and paste its own #slide=… URL into the module instead: Slides addresses slides by internal id, and a deck imported from PowerPoint doesn't get sequential ids.
